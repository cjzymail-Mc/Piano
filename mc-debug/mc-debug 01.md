 # 三和弦 vs 七和弦
 流行乐理中，每个大调都有最常用的
  3和弦，让你制作的这些是标准的3和弦，没错吧？
  那对应的最常用7个7和弦是什么？用和弦级数列给我



● 对——你让我做的就是每个大调自然音阶内顺阶叠置的标准三和弦（每个音
  阶级上三度叠两层的“本地”和弦），级数与性质固定为：

  I（大）· ii（小）· iii（小）· IV（大）· V（大）· vi（小）·
  vii°（减）

  这就是流行/爵士乐理里说的大调“七件套”，三和弦层面完全标准 ✓

  对应的 7 个七和弦（顺阶七和弦）

  在三和弦上再叠一个三度，级数和性质同样固定：

  ┌─────────┬──────────────┬──────────────────────────────────┐
  │  级数   │  七和弦性质  │          流行乐中的作用          │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ Imaj7   │ 大三大五大七 │ 主功能，梦幻/爵士感结尾          │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ iim7    │ 小三小三小七 │ 经典 ii–V–I 的起点               │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ iiim7   │ 小三小三小七 │ 替代 I，色彩偏飘                 │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ IVmaj7  │ 大三大五大七 │ 温柔的下属功能                   │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ V7      │ 大三大五小七 │ 属七——整个体系里最“要解决”的和弦 │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ vim7    │ 小三小三小七 │ 桥段/伪终止（V7→vim）            │
  ├─────────┼──────────────┼──────────────────────────────────┤
  │ viim7♭5 │ 小三减五小七 │ 半减，流行里少用，常被 V7 替代   │
  └─────────┴──────────────┴──────────────────────────────────┘

  三个调的具体音：

  ┌─────────┬─────────┬──────────┬──────────┐
  │  级数   │ C 大调  │  G 大调  │  F 大调  │
  ├─────────┼─────────┼──────────┼──────────┤
  │ Imaj7   │ C–E–G–B │ G–B–D–F♯ │ F–A–C–E  │
  ├─────────┼─────────┼──────────┼──────────┤
  │ iim7    │ D–F–A–C │ A–C–E–G  │ G–B♭–D–F │
  ├─────────┼─────────┼──────────┼──────────┤
  │ iiim7   │ E–G–B–D │ B–D–F♯–A │ A–C–E–G  │
  ├─────────┼─────────┼──────────┼──────────┤
  │ IVmaj7  │ F–A–C–E │ C–E–G–B  │ B♭–D–F–A │
  ├─────────┼─────────┼──────────┼──────────┤
  │ V7      │ G–B–D–F │ D–F♯–A–C │ C–E–G–B♭ │
  ├─────────┼─────────┼──────────┼──────────┤
  │ vim7    │ A–C–E–G │ E–G–B–D  │ D–F–A–C  │
  ├─────────┼─────────┼──────────┼──────────┤
  │ viim7♭5 │ B–D–F–A │ F♯–A–C–E │ E–G–B♭–D │
  └─────────┴─────────┴──────────┴──────────┘

  记忆口诀就一行：maj7 · m7 · m7 · maj7 · 7 · m7 ·
  m7♭5（大七、小七、小七、大七、属七、小七、半减）。
